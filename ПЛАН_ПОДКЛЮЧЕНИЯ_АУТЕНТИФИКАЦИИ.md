На основе анализа MD файла и существующей архитектуры, создаю детальный план по интеграции аутентификации:

## 📋 Обзор задач

### 1. **Inventory сервис - gRPC интерцептор аутентификации**
- Добавить конфигурацию IAM gRPC клиента
- Подключить gRPC интерцептор для проверки сессий
- Обновить DI контейнер

### 2. **Order сервис - HTTP middleware аутентификации**  
- Добавить конфигурацию IAM gRPC клиента
- Подключить HTTP middleware для проверки сессий

package env

import (
    "net"
    "github.com/caarlos0/env/v11"
)

type iamGrpcEnvConfig struct {
    Host string `env:"IAM_GRPC_HOST,required"`
    Port string `env:"IAM_GRPC_PORT,required"`
}

type iamGrpcConfig struct {
    raw iamGrpcEnvConfig
}

func NewIamGrpcConfig() (*iamGrpcConfig, error) {
    var raw iamGrpcEnvConfig

#### 1.4 Обновить DI контейнер
```go
// inventory/internal/app/di.go
import (
    "github.com/space-wanderer/microservices/platform/pkg/middleware/grpc"
    authV1 "github.com/space-wanderer/microservices/shared/pkg/proto/auth/v1"
)

type diContainer struct {
    // ... существующие поля
    iamGrpcClient   authV1.AuthServiceClient
    authInterceptor *grpc.AuthInterceptor
}

func (d *diContainer) IamGrpcClient(ctx context.Context) authV1.AuthServiceClient {
    if d.iamGrpcClient == nil {
        iamConfig := config.AppConfig().IamGrpc
        
        conn, err := grpc.Dial(iamConfig.Address(), grpc.WithInsecure())
        if err != nil {
            panic(fmt.Sprintf("failed to connect to IAM gRPC: %v", err))
        }
        
        d.iamGrpcClient = authV1.NewAuthServiceClient(conn)
    }
    return d.iamGrpcClient
}

func (d *diContainer) AuthInterceptor(ctx context.Context) *grpc.AuthInterceptor {
    if d.authInterceptor == nil {
        iamClient := d.IamGrpcClient(ctx)
        d.authInterceptor = grpc.NewAuthInterceptor(iamClient)
    }
    return d.authInterceptor
}
```

#### 1.5 Подключить интерцептор к gRPC серверу

    )

    inventoryV1.RegisterInventoryServiceServer(a.grpcServer, inventoryAPI)
    
    // ... остальная инициализация
    return nil
}

import (

type diContainer struct {

#### 2.5 Подключить middleware к HTTP серверу

// order/internal/app/app.go
func (a *App) initHTTPServer(ctx context.Context) error {
    // Создаем HTTP сервер с middleware
    authMiddleware := a.diContainer.AuthMiddleware(ctx)
    
    mux := http.NewServeMux()
    
    // Регистрируем handlers
    orderAPI := a.diContainer.OrderV1API(ctx)
    orderAPI.RegisterHandlers(mux)
    
    // Применяем middleware
    handler := authMiddleware.Handle(mux)
    
    // Запускаем сервер
    httpConfig := config.AppConfig().OrderHTTP
    server := &http.Server{
        Addr:    httpConfig.Address(),
        Handler: handler,
    }
    
    // ... запуск сервера
    return nil
}

### **Этап 5: Тестирование интеграции**

#### 5.1 Сценарий тестирования
1. **Регистрация пользователя** через IAM сервис
2. **Логин пользователя** через IAM сервис (получение session UUID)
3. **HTTP запрос к Order сервису** с заголовком `X-Session-Uuid`
4. **Order сервис** проверяет сессию через IAM и вызывает Inventory
5. **Inventory сервис** получает session UUID в gRPC metadata и проверяет через IAM

#### 5.2 Проверка цепочки аутентификации
```
Client (HTTP) -> Order (HTTP middleware) -> IAM (Whoami) -> Order (gRPC client) -> Inventory (gRPC interceptor) -> IAM (Whoami)
```

## 🔧 Технические детали

### **Передача сессий между сервисами:**
- **HTTP → Order**: `X-Session-Uuid` заголовок
- **Order → Inventory**: `session-uuid` gRPC metadata
- **Контекст**: session UUID и пользователь сохраняются в контексте

### **Валидация сессий:**
- Все сервисы проверяют сессии через `IAM.Whoami()`
- Сессии хранятся в Redis с TTL 24 часа
- При невалидной сессии возвращается `Unauthenticated` ошибка

### **Безопасность:**
- Сессии передаются только через защищенные каналы
- Каждый запрос валидируется независимо
- Нет кеширования результатов аутентификации

### **Обработка ошибок:**
- `Unauthenticated` - отсутствует или невалидная сессия
- `Unauthorized` - пользователь не имеет прав доступа
- `Internal` - ошибка при обращении к IAM сервису
